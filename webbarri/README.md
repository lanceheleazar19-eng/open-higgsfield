# WebBarri

Web del servicio de páginas web para negocios de Barcelona, con tres webs de
ejemplo de negocios inventados (`ejemplos/`).

**Antes de publicar:** cambia `34600000000` por tu número de WhatsApp (con 34
delante, sin espacios) en `index.html`. En los ejemplos puedes dejar el número
inventado.

**Publicar gratis en Netlify:** entra en app.netlify.com/drop y arrastra esta
carpeta `webbarri` entera. En un minuto tendrás un enlace `*.netlify.app`.

Anuncios y vídeos: `docs/webs-negocios/anuncios-y-videos.md`.
